## About

Software Engineering student at **FPT University HCMC** and **Frontend Developer Intern at VNZ Company**. I build modern, production-grade web interfaces with **Next.js, React and TypeScript**, focusing on clean component architecture, consistent design systems and smooth user experiences.

At work I contribute to **BMT AI Construction**, a construction-intelligence SaaS platform, where I turn product designs into responsive, accessible pages backed by a typed data layer and a separate .NET REST API. Outside work I build my own projects to sharpen the fundamentals — from component libraries and end-to-end tests to Java unit testing with TDD.

I care about the details users notice: spacing, states, theming, localization — and code that stays readable as the product grows.

## How I Build

> **Components first.** Small, reusable building blocks on top of a shared design system, so every screen looks and behaves consistently.
>
> **Type-safe end to end.** Strict TypeScript, Zod schemas for forms and environment variables, typed API calls — fewer surprises in production.
>
> **Every state matters.** Loading, empty, error, dark mode and a second language are part of the feature, not an afterthought.
>
> **Tested and automated.** Playwright for user flows, JUnit for logic, GitHub Actions to run them on every push.
>
> *A good interface is invisible: users just get things done.*

Areas of focus: `Component Architecture` &nbsp;`Design Systems` &nbsp;`Responsive UI` &nbsp;`State Management` &nbsp;`i18n and Theming` &nbsp;`Testing`
